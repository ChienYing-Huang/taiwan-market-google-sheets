# StockMarketGoogleSheets v1.5 升級說明

## 修正內容

Google Sheets 可能將同樣顯示為 `2026-08-06` 的資料儲存成不同型別：

- 日期物件
- 文字 `2026-08-06`

舊版直接比較底層值，因此可能將同一交易日判斷成兩個日期並產生重複列。

v1.5 會：

1. 將所有籌碼日期統一成文字 `yyyy-MM-dd`。
2. 以標準化後的日期作為唯一鍵。
3. 自動合併「每日籌碼」中既有的同日重複列。
4. 合併數值、資料來源、更新時間與狀態，不會直接丟棄已有欄位。

## 更新方式

1. 開啟 Google 試算表。
2. 選擇「擴充功能 → Apps Script」。
3. 將目前 `Code.gs` 全部替換為 `StockMarketGoogleSheets_v1.5.gs`。
4. 儲存。
5. 執行一次 `repairChipSheetDuplicates`。
6. 再執行一次 `updateMarketData` 測試。

原有 20:00 排程不需要重建，因為排程仍呼叫 `updateMarketData`。
