# StockMarketGoogleSheets v2.1.1 — 總表欄位調整

本版以 **v2.1** 為基礎，只修改「總表」欄位配置。
資料擷取、50 點價平履約價、IV 計算與每日增量更新邏輯均維持 v2.1。

## 調整項目

### 1. 選擇權 OI 移除「到期日」

三個 OI 區塊皆改為 5 欄：

- 契約
- Call最大OI履約價
- Call最大OI
- Put最大OI履約價
- Put最大OI

區塊：
- 週選擇權 W (OI)
- 週選擇權 F (OI)
- 月選擇權 (OI)

### 2. 選擇權 IV 移除「到期日」並調整欄位順序

三個 IV 區塊皆改為：

1. 契約
2. Call IV(>35)
3. Call成交價
4. 價平履約價
5. Put成交價
6. Put IV(>35)

區塊：
- 週選擇權 W (IV)
- 週選擇權 F (IV)
- 月選擇權 (IV)

### 3. 總表欄數

- v2.1：67 欄
- v2.1.1：61 欄

第一次執行 v2.1.1 時會自動重建一次「總表」完成欄位遷移，
並清除舊版 BJ:BO 的殘留欄位內容。

之後仍採增量更新：
- 新交易日：新增一列
- 同一天重跑：更新原列
- 不會每天重建整份總表

## 升級方式

1. Google 試算表 → 擴充功能 → Apps Script
2. 將目前 Code.gs 全部替換為 `StockMarketGoogleSheets_v2.1.1.gs`
3. 儲存
4. 執行一次 `updateMarketData()`

第一次執行會進行一次總表版型遷移。
原本每日 20:00 的觸發器不需重新建立。
