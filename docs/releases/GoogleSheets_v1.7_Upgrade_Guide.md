# Google 試算表台股更新器 v1.7 升級說明

## 新增內容

v1.7 新增「總表」工作表，版型參考附件 `大盤每日紀錄_亮東(1).ods` 中「亮東調整」的分區式雙層表頭。

總表會依「資料日期」整合既有三張來源表：

- 每日行情
- 每日籌碼
- 選擇權OI

一個交易日只保留一列。

## 總表欄位

1. 資料日期、星期
2. 大盤現貨指數：開盤、最高、最低、收盤、漲跌
3. 台指期貨指數：契約月份、開盤、最高、最低、收盤、正逆價差
4. 週選擇權 W：契約、Call 最大 OI 履約價／OI、Put 最大 OI 履約價／OI、到期日
5. 週選擇權 F：契約、Call 最大 OI 履約價／OI、Put 最大 OI 履約價／OI、到期日
6. 月選擇權：契約、Call 最大 OI 履約價／OI、Put 最大 OI 履約價／OI、到期日
7. 市場籌碼：P/C 未平倉量比、小台散戶多空比、微台散戶多空比
8. 台指期未平倉：前五大、前十大、前五特法、前十特法、外資、投信、自營商
9. 更新時間、完整性狀態、資料來源

## 衍生欄位

- 大盤漲跌＝當日現貨收盤－前一個可用交易日現貨收盤
- 正逆價差＝台指期日盤收盤－大盤現貨收盤

## 日期處理

總表不會強制把不同日期的來源合併。

例如期交所某一來源尚未更新時，該日期會標示「部分資料」；待來源更新後再次執行，程式會自動補齊同一日期的原列。

## 升級步驟

1. 開啟 Google 試算表。
2. 選擇「擴充功能 → Apps Script」。
3. 將目前 `Code.gs` 全部替換為 `StockMarketGoogleSheets_v1.7.gs`。
4. 儲存。
5. 執行 `initializeSheets` 一次。
6. 執行 `updateMarketData` 一次。

原本 20:00 排程仍會呼叫 `updateMarketData`，不需要重新建立排程。

## 手動重建總表

重新開啟試算表後，可使用：

`台股行情工具 → 重建總表`

總表會直接從三張來源表重新整理，不會重新抓取網頁。
