# Google 試算表台股行情更新器

這個版本會將下列資料自動寫入 Google 試算表：

- 大盤現貨指數：開盤、最高、最低、收盤
- 台指期貨指數（日盤近月契約）：開盤、最高、最低、收盤

資料來源：

- 臺灣證券交易所
- 臺灣期貨交易所

## 安裝步驟

1. 建立一份空白 Google 試算表。
2. 點選「擴充功能 → Apps Script」。
3. 刪除 Code.gs 原有內容。
4. 將 `StockMarketGoogleSheets.gs` 的全部內容貼入。
5. 儲存專案。
6. 在上方函式選單選擇 `setupMarketUpdater`。
7. 按「執行」。
8. 依畫面完成 Google 權限授權。
9. 回到試算表，應會看到：
   - 每日行情
   - 執行紀錄

## 排程

`setupMarketUpdater()` 會建立每天台北時間約 20:00 的排程。

Google Apps Script 的 `nearMinute(0)` 有約 ±15 分鐘的容許誤差，因此實際執行可能落在約 19:45–20:15。

程式會略過週六、週日。遇到平日休市時，不會建立不存在的交易日，而是保留或更新最近可用交易日資料。

## 手動測試

在 Apps Script 執行：

`updateMarketData`

或重新開啟試算表，在上方選單使用：

「台股行情工具 → 立即更新」

## 欄位

- 資料日期
- 商品
- 契約月份
- 開盤
- 最高
- 最低
- 收盤
- 資料來源
- 更新時間
- 狀態

同一個「資料日期＋商品」重複執行時會更新原列，不會新增重複資料。
