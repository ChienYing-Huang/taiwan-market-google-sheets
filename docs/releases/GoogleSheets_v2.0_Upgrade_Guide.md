# Google Sheets 台股更新器 v2.0 升級說明

## 本次調整

### 1. 總表將選擇權 OI 與 IV 拆成六個區塊

總表由左至右排列為：

1. 資料日期
2. 星期
3. 大盤現貨指數
4. 台指期貨指數
5. 週選擇權 W (OI)
6. 週選擇權 F (OI)
7. 月選擇權 (OI)
8. 週選擇權 W (IV)
9. 週選擇權 F (IV)
10. 月選擇權 (IV)
11. 市場籌碼
12. 台指期未平倉（大額近月、法人所有月）

OI 區塊欄位：

- 契約
- Call 最大 OI 履約價
- Call 最大 OI
- Put 最大 OI 履約價
- Put 最大 OI
- 到期日

IV 區塊欄位：

- 契約
- 價平履約價
- Call 成交價
- Call IV(>35)
- Put 成交價
- Put IV(>35)
- 到期日

### 2. 移除總表更新資訊

總表不再顯示：

- 更新時間
- 狀態
- 資料來源

上述欄位仍保留在各來源工作表，方便除錯與核對。

### 3. 大盤現貨新增欄位

- 成交量(張)
- 上影線
- 下影線
- 十字線
- K棒長度

計算公式：

- 上影線 = 最高 − MAX(收盤, 開盤)
- 下影線 = MIN(收盤, 開盤) − 最低
- 十字線 = ABS(收盤 − 開盤)
- K棒長度 = 收盤 − 開盤 − 上影線 + 下影線

### 4. 大盤成交量

資料取自臺灣證券交易所「每日市場成交資訊」的成交股數，除以 1,000 並四捨五入後，以「張」寫入。

每日行情工作表會新增：

- 成交量(張)

## 升級步驟

1. 開啟 Google 試算表。
2. 選擇「擴充功能 → Apps Script」。
3. 將目前 `Code.gs` 的內容全部替換成 `StockMarketGoogleSheets_v2.0.gs`。
4. 儲存。
5. 執行一次 `updateMarketData()`。

第一次執行 v2.0 時，因總表欄位結構改變，會進行一次完整總表遷移。遷移完成後，日常排程仍採增量模式：

- 新交易日：新增一列。
- 同一天重跑：更新原列。
- 歷史資料：不會每天重新建立。

原本 20:00 的觸發器仍會呼叫 `updateMarketData()`，不需要重新建立排程。

## 注意事項

- K 棒計算可由既有 OHLC 直接重建，因此歷史列也會自動產生。
- 成交量從 v2.0 開始隨每日更新寫入；先前沒有擷取成交量的歷史日期會保持空白。
- IV 大於 35 的儲存格仍會以紅字與底色標示。
