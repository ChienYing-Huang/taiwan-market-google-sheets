# StockMarketGoogleSheets v1.4 升級說明

## 修正內容

玩股網會對 Google Apps Script 的伺服器請求回傳 HTTP 403，因此 v1.4 不再直接抓取玩股網的小台指與微台指散戶多空比。

新版改由臺灣期貨交易所官方資料推算：

- 全市場未平倉量：期貨每日交易行情（日盤）
- 法人多方／空方未平倉量：三大法人－區分各期貨契約－依日期

計算方式：

```text
散戶多單 = 全市場未平倉量 - 三大法人多方未平倉量
散戶空單 = 全市場未平倉量 - 三大法人空方未平倉量
散戶多空比 = (散戶多單 - 散戶空單) / 全市場未平倉量 × 100%
```

## 升級步驟

1. 開啟原本的 Google 試算表。
2. 點選「擴充功能 → Apps Script」。
3. 將 Code.gs 原有內容全部刪除。
4. 貼上 `StockMarketGoogleSheets_v1.4.gs` 的完整內容。
5. 儲存。
6. 執行 `updateMarketData` 測試。

原有排程仍會呼叫同名的 `updateMarketData`，不需要重新建立觸發器。

## 預期測試結果

以 2026-08-06 為例：

- 小台指散戶多空比：32.30%
- 微台指散戶多空比：37.16%

執行紀錄應顯示類似：

```text
完成：大盤現貨 2026-08-06、台指期 2026-08-06 202608、小台散戶比 2026-08-06、微台散戶比 2026-08-06、P/C未平倉比 2026-08-06、大額法人未平倉 2026-08-06
```

## 安全檢查

若全市場未平倉量與三大法人資料日期不同，或推算出的散戶多空部位為負數，程式會停止寫入該指標並在「執行紀錄」留下錯誤，避免混用不同日期的資料。
