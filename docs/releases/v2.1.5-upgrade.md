# StockMarketGoogleSheets v2.1.5 升級說明

發布日期：2026-09-18。基準：GitHub `ChienYing-Huang/taiwan-market-google-sheets` 的 v2.1.4 程式。

## 本次修正

### 1. 2026-09-16 大盤資料未寫入

使用者提供的執行紀錄顯示：`HTTP 307` 發生在 `date=20260801` 的 8 月指數請求。v2.1.4 會無條件依序請求本月及上月；即使本月已成功，上月請求拋錯仍會使整個大盤擷取中止。

v2.1.5 在本月已有有效資料時直接採用，不再請求上月。只有本月回應成功且確實無資料時，才查上月；本月全面失敗時會明確報錯，不拿過期行情冒充成功。

最新行情與指定日期的歷史修復共用同一解析器，支援頂層或 `tables` 內的行情表，驗證資料月份及 OHLC。主路徑失敗時有限次重試，並改查證交所官方 `indicesReport` 路徑；每個路徑最多兩次。這處理的是資料流程及暫時故障；無法由歷史紀錄判定證交所當時回傳 307 的伺服器端原因。

### 2. 2026-09-17 價平履約價

已依本次確認的需求修正季節切換規則：

- 1–4 月：大盤現貨收盤。
- 5 月起至 9 月月契約結算日前：台指期日盤收盤。
- **9 月結算當日起至年底：大盤現貨收盤。** 2026 年切換日為 09-16。
- 結算日沿用既有契約到期日推算及休市順延判斷。

09-17 台指期近月已為 `202610`，收盤 46,445。舊版只看資料月份仍是 9 月，所以選出 46,450；新版改用同日現貨收盤 46,288，得到 **46,300**。

另修正實際掛牌檔位問題：當天 `202610` 月選沒有 46,450，但 W、F 有。新版先保留原來「四捨五入至 50 點」的目標；若該契約沒有 Call、Put 雙邊掛牌的目標履約價，就以**未四捨五入的基準價**選最近的雙邊掛牌履約價，等距取較高者。不同契約因此不保證永遠顯示相同履約價。無成交價不等於未掛牌，不為了取得成交價而跳到更遠的檔位。

本次未更動最大 OI 的定義、W1 → W2 → 月選 → W4 → W5 序列、到期日當天換下一契約、IV 的現貨標的及交易日年化參數。單一契約 ATM 計算失敗不再阻止其餘契約計算。基準來源、基準價與實際履約價會寫入「選擇權OI」狀態及歷史修復紀錄；不完整的 ATM／IV 明確標示。

## 升級操作

1. 先複製一份目前試算表作備份，並保存原來的 `Code.gs`（若有自訂 CONFIG，請一併保留）。
2. 在原試算表開啟「擴充功能 → Apps Script」，用隨附的 `StockMarketGoogleSheets_v2.1.5.gs` **完整取代**原 `Code.gs`，不要另新增一份重複程式。
3. 若原來有自訂工作表名稱或 IV 設定，對照 CONFIG 後套回；儲存，重新整理試算表。
4. 選「台股行情工具 → 重新抓取歷史區間」，開始日期填 `2026-09-16`、結束日期填 `2026-09-17`。
5. 等待完成，檢查「歷史修復紀錄」；必要時用「查看歷史修復狀態」確認。先修復每日行情，再計算選擇權與總表，程式會依此順序執行。
6. 對照下列驗收值。若來源失敗，保留錯誤紀錄並於稍後重跑該區間。

總表仍為 61 欄，不需重建版型，也不需重新執行 `setupMarketUpdater()` 或重建原每日排程。升級程式本身不會自動回填歷史；第 4 步才會覆寫指定日期的來源資料與總表。只執行「重建總表」無法修正原始擷取資料。

## 測試與限制

已用 09-16、09-17 官方完整選擇權 HTML、9 月指數及成交量 JSON、2026 休市表離線回放，10 項回歸測試通過；程式可由 JavaScript 引擎完整解析。兩天的 OI／ATM／IV 及歷史指定日期路徑均已驗證。

此驗證模擬 Apps Script 的網路、日期及快取服務，未連入你的 Apps Script 執行環境，也未修改線上試算表或排程。正式環境的授權、網路及寫表結果，請依上述升級與驗收步驟確認。IV 為本程式估算值，沿用原參數，並非期交所直接公布值。

## 版本留存與回復

發布套件包含完整新版程式、升級說明、修改差異、回歸測試及公開來源快照；`archive/releases/v2.1.4` 保存未修改的舊版程式。舊版開發紀錄保留，新規則另列為 v2.1.5，不回寫舊版說明。

GitHub 正式版本以 `v2.1.5` tag 留存；原有 commit、tag 及實驗分支保留。回歸測試及官方快照位於 `tests/`，執行 `node tests/regression.cjs` 可重跑驗證。

若需回復，將保存的 v2.1.4 程式貼回。回復程式不會自動還原已回填的試算表資料；資料請從第 1 步的備份或試算表版本紀錄還原。
