# OneDrive v2.2 Experiment — Not Adopted

狀態：**Archived / not part of stable mainline**

目的：透過 Microsoft Graph API 將 Google「總表」增量同步至 OneDrive Excel。

結果：完成原型，但後續決定暫不採用 API 同步，正式版本繼續沿用 v2.1.x 主線。

替代方案：Google Sheets 可將總表發布成 CSV，再由 Excel Power Query 或 LibreOffice Calc 外部資料功能讀取。

完整實驗程式保留在 Git branch：`experimental/onedrive-v2.2`。
