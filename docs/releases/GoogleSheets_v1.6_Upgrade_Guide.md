# Google 試算表台股更新器 v1.6 升級說明

## 新增功能

v1.6 新增「選擇權OI」工作表，每個交易日記錄臺指選擇權三類前端有效契約：

1. 月選契約：`YYYYMM`
2. 週三到期契約：`YYYYMMW1`、`W2`、`W4`、`W5`
3. 週五到期契約：`YYYYMMF1`～`F5`

每一類契約分別記錄：

- 契約代碼
- 契約到期日
- 買權最大未平倉量的履約價
- 買權最大未平倉量
- 賣權最大未平倉量的履約價
- 賣權最大未平倉量

資料來源欄、更新時間與資料狀態也會一併保存。

## 契約選擇規則

程式不自行用日曆推算週別，而是直接讀取期交所完整日盤行情中的契約代碼、契約到期日及未平倉量：

- 月選：選取最早到期且仍有正數 OI 的六碼月份契約。
- W：選取最早到期且仍有正數 OI 的 `W1/W2/W4/W5` 契約。
- F：選取最早到期且仍有正數 OI 的 `F1/F2/F3/F4/F5` 契約。
- 第三個星期三由月選契約承接，因此不會尋找不存在的 `W3`。
- 若休市造成結算順延，只要原契約仍有正數 OI，程式仍會選取該契約。
- 結算完成後，若到期契約 OI 歸零或不再揭露，程式會自動換到下一個有效契約。
- 若最大 OI 有多個履約價並列，履約價會以 `／` 串接保存。

## 資料來源順序

1. 臺灣期貨交易所「選擇權每日交易行情查詢」完整日盤行情頁
2. 臺灣期貨交易所 OpenAPI
3. 臺灣期貨交易所官方 CSV

主來源使用完整行情表，不使用只摘錄活絡序列的行情簡表。

## 更新步驟

1. 開啟原本的 Google 試算表。
2. 選擇「擴充功能 → Apps Script」。
3. 將目前 `Code.gs` 全部替換成 `StockMarketGoogleSheets_v1.6.gs`。
4. 儲存。
5. 先執行 `initializeSheets`，建立「選擇權OI」工作表。
6. 再執行 `updateMarketData` 測試當日更新。

原本的每日排程仍呼叫 `updateMarketData`，不需要重新建立觸發器。
