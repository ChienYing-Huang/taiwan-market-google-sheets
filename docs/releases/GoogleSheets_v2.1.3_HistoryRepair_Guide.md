# StockMarketGoogleSheets v2.1.3 — 歷史區間重新抓取／修復

本版延續 v2.1.2 的所有功能，新增「指定日期區間重新抓取」功能，
用途是重新驗證及覆寫過去可能曾因網站更新延遲、契約切換或解析問題而寫錯的資料。

## 功能原則

1. **只覆寫成功取得且資料日期完全一致的來源**
   - 若網站忽略歷史日期、回傳最新日或抓取失敗，原本資料會保留。
   - 不會因單一來源失敗而把舊資料清空。

2. **逐交易日重新抓取**
   - 大盤現貨 OHLC + 成交量
   - 台指期日盤 OHLC
   - 小台／微台散戶多空比
   - P/C 未平倉量比
   - 聚財網大額／法人未平倉
   - 月選、W、F 的 OI / 價平履約價 / 成交價 / IV
   - 修復後重新計算當日總表

3. **沿用 v2.1.2 契約切換規則**
   - 到期日當天不使用到期契約
   - 月選改下一個月契約
   - W 只允許 W1、W2、W4、W5，不存在 W3
   - F 使用下一個尚未到期的 F 契約

4. **分批處理避免 Apps Script 逾時**
   - 每批預設 2 個交易日。
   - 完成一批後建立一次性觸發器，約 1 分鐘後繼續。
   - 單次區間最多 93 個日曆日；更長期間建議分段修復。

5. **新增「歷史修復紀錄」工作表**
   每個日期與來源都會記錄：
   - 成功覆寫
   - 保留舊值
   - 略過非交易日
   - 總表更新狀態

## 升級

1. Google Sheets → 擴充功能 → Apps Script
2. 將目前 Code.gs 替換成 `StockMarketGoogleSheets_v2.1.3_HistoryRepair.gs`
3. 儲存
4. 重新整理 Google Sheets 頁面
5. 不需重建每日 20:00 排程

## 使用

選單：

`台股行情工具 → 重新抓取歷史區間`

依序輸入：

- 開始日期，例如：`2026-08-01`
- 結束日期，例如：`2026-08-10`

結束日期必須早於今天。

啟動後可使用：

- `查看歷史修復狀態`
- `取消歷史修復`

## 安全策略

歷史頁面有時可能忽略 queryDate 而回傳最新資料，因此 v2.1.3 會再次解析頁面
實際顯示的資料日期。只有「要求日期 = 頁面日期」時才允許覆寫。

這是歷史修復最重要的保護機制，可避免把最新一日資料誤寫到過去日期。

## 資料來源限制

- TWSE 加權指數及成交量：使用證交所官方歷史資料。
- TAIFEX 期貨／選擇權：使用期交所歷史查詢頁；程式同時嘗試 GET 與 POST 查詢。
- P/C 比：先從期交所目前表格找指定日期，找不到再嘗試起訖日查詢。
- 聚財網：其頁面本身保留一段近期歷史；若指定日期已超出頁面可見範圍，
  程式會記錄「保留舊值」，不會刪除舊資料。
- 三大法人歷史資料可查詢期間受到期交所網站提供範圍限制。

## 建議

第一次先測試 3–5 個交易日，例如：

`2026-08-03 ～ 2026-08-07`

確認「歷史修復紀錄」中各來源皆能正確重新取得後，再擴大到較長區間。
