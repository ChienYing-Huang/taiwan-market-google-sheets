# Google Sheets 台股更新器 v1.8 升級說明

## 本版重點

v1.8 將「總表」由每日完整重建改為增量更新：

- 每次排程只處理本次抓取成功的資料日期。
- 新交易日：在總表新增一列。
- 同一日期重跑：更新原本的列，不會重複新增。
- 不再清除並重寫全部歷史資料。
- 若不同來源的最新日期不一致，會分別更新對應日期，不會把舊資料誤填為今天。
- 手動「重建總表」功能仍保留，僅在首次匯入歷史資料或需要修復時使用。

## 升級步驟

1. 開啟 Google 試算表。
2. 選擇「擴充功能 → Apps Script」。
3. 將目前 Code.gs 的內容全部替換成 `StockMarketGoogleSheets_v1.8.gs`。
4. 儲存。
5. 執行一次 `updateMarketData`。
6. 首次執行 v1.8 時，程式會一次性將總表的交錯底色改成適合增量新增的逐列格式。

原本的每日排程仍呼叫 `updateMarketData`，不必重新建立觸發器。

## 每日執行結果

新交易日第一次執行時，紀錄會類似：

```text
總表新增 1 列、更新 0 列
```

同一天再次執行、補齊較晚更新的資料時，紀錄會類似：

```text
總表新增 0 列、更新 1 列
```

## 選單功能

重新開啟試算表後，「台股行情工具」選單會包含：

- 立即更新：重新抓取網頁資料，並增量更新總表。
- 更新最近資料至總表：不重新抓網頁，只將三張來源表最新日期寫入總表。
- 重建總表（手動修復）：重新掃描所有歷史來源資料並建立整份總表；平日不需使用。

## 效能調整

v1.8 的每日排程不再執行下列動作：

- 清空總表全部資料列。
- 重寫全部歷史紀錄。
- 每日重新建立整張總表的交錯列格式。
- 每日掃描並合併來源表的歷史重複列。

只有在手動執行「重建總表（手動修復）」時，才會重新處理全部歷史資料。
