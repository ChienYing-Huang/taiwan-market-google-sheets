# Google 試算表台股更新器 v1.3 升級說明

## 新增資料

新版新增「每日籌碼」工作表，欄位如下：

- 資料日期
- 小台指散戶多空比(%)
- 微台指散戶多空比(%)
- 買賣權未平倉量比率(%)
- 前五大
- 前十大
- 前五特法
- 前十特法
- 外資
- 投信
- 自營商
- 資料來源
- 更新時間
- 狀態

## 資料來源

1. 小台指散戶多空比：玩股網 `wmt&`
2. 微台指散戶多空比：玩股網 `wtm&`
3. 買賣權未平倉量比率：臺灣期貨交易所 Put/Call 比頁面
4. 前五大、前十大、前五特法、前十特法、外資、投信、自營商：聚財網台指期未平倉資料頁

## 升級步驟

1. 開啟原本 Google 試算表。
2. 點選「擴充功能 → Apps Script」。
3. 將 `Code.gs` 內容全部刪除。
4. 貼入 `StockMarketGoogleSheets_v1.3.gs` 的完整內容。
5. 儲存。
6. 在函式選單選擇 `initializeSheets` 並執行一次。
7. 再選擇 `updateMarketData` 執行測試。

原有排程仍會呼叫同名的 `updateMarketData`，因此不必重建排程。若希望重新建立，也可執行 `createDailyTrigger`。

## 日期合併規則

各來源以網頁實際顯示的資料日期為準：

- 同一天的資料會合併到「每日籌碼」的同一列。
- 若某個網站尚未更新，舊日期資料會留在舊日期列，不會錯誤填入今天。
- 相同日期重複執行會更新原列，不會產生重複資料。
